# VetGroom

Site institucional da VetGroom, desenvolvido com React, Vite e TypeScript.

## Executar localmente

Requer Node.js 22 ou superior.

```bash
npm ci --legacy-peer-deps
npm run dev
```

## Publicação

O GitHub Actions publica automaticamente o conteúdo de `main` no GitHub Pages:

https://pedrohtrag.github.io/Novo-Site-VetGroom/

Para validar a versão de produção localmente:

```bash
npm run lint
npm run build
npm run preview
```
